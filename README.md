A clean and straightforward web application for managing your daily tasks. Add items to your list, mark them as complete when done, and remove them when no longer needed. Your tasks are automatically saved in your browser's local storage, so you won't lose them even if you close the page!

## ✨ Features

*   **Add Tasks:** Quickly add new tasks via the input field.
*   **Mark as Complete:** Simply click on a task to toggle its completion status (visually indicated by a strikethrough and checkmark).
*   **Delete Tasks:** Remove tasks easily by clicking the 'x' icon next to them.
*   **Persistent Storage:** Tasks persist between browser sessions using Local Storage.
*   **User-Friendly Interface:** Clean and intuitive design.

## ⚙️ Getting Started

This is a purely client-side application, meaning you don't need any special server setup to run it locally.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/shubhambhagat3226/To-Do-List.git
    ```

2.  **Navigate to the directory:**
    ```bash
    cd shubhambhagat3226-to-do-list
    ```

3.  **Open the `index.html` file:**
    Simply double-click the `index.html` file, or right-click and choose "Open with" your preferred web browser (like Chrome, Firefox, Edge).

That's it! The To-Do List app should now be running in your browser.

## 📝 How to Use

1.  **Add a Task:** Type your task into the input field labeled "Add your text" and click the "Add" button.
2.  **Mark a Task as Complete:** Click directly on the text of the task in the list. Click again to unmark it.
3.  **Delete a Task:** Click the `×` (cross icon) that appears to the right of a task when you hover over it (or on touch devices, it might be always visible).
